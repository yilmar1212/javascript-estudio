# Curso de JavaScript

Este repositorio contiene ejemplos básicos que use en JavaScript para aprender los fundamentos del lenguaje.

## Estructura del proyecto

- `01-fundamentos/`
  - `index.html` - Página HTML principal que carga el script de JavaScript.
  - `app.js` - Archivo JavaScript con ejemplos iniciales y comentarios explicativos.

## ¿Qué incluye?

En `01-fundamentos/app.js` hay una introducción a `console.log()` y cómo se usa para imprimir mensajes en la consola del navegador, ideal para depuración y aprendizaje.

## Cómo usarlo

1. Abre `01-fundamentos/index.html` en tu navegador.
2. Abre la consola del desarrollador (normalmente con F12 o Ctrl+Shift+I).
3. Verás las instrucciones y ejemplos de JavaScript ejecutándose desde `app.js`.

## Notas

- Este proyecto está pensado para los primeros pasos con JavaScript.
- Puedes editar `app.js` y recargar la página para probar nuevos ejemplos.
